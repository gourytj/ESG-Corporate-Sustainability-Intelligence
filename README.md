# ESG & Corporate Sustainability Intelligence

## Project Overview
This project focuses on analyzing Environmental, Social, and Governance (ESG) performance alongside the financial performance of companies using Microsoft Power BI.

The dashboard provides insights into corporate sustainability, financial trends, environmental performance, and company-level ESG benchmarking.

## Project Objectives
- Analyze overall ESG performance across companies.
- Evaluate Environmental, Social, and Governance scores.
- Compare financial performance across industries and regions.
- Analyze carbon emissions and environmental sustainability.
- Identify top-performing companies based on ESG scores.
- Compare individual company ESG performance with industry averages.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel
- Kaggle Dataset

## Dataset Description
The project uses the **ESG and Financial Performance Dataset** from Kaggle.

The dataset contains company-level ESG and financial information, including:
- Company Name
- Reporting Year
- Industry
- Region
- Revenue
- Profit Margin
- Growth Rate
- Market Capitalization
- Overall ESG Score
- Environmental Score
- Social Score
- Governance Score
- Carbon Emissions

## Data Cleaning and Transformation
- Checked data quality using Power Query.
- Handled missing values.
- Corrected column data types.
- Reviewed duplicates and data consistency.
- Transformed and prepared data for analysis.
- Created readable company names using a mapping table.

## Dashboard Pages

### 1. Executive ESG Overview
Provides an overall summary of company performance using KPI cards, charts, and interactive filters.

### 2. Financial Performance Analysis
Analyzes revenue, profit margin, growth rate, and market capitalization across companies and industries.

### 3. Environmental Sustainability Analysis
Focuses on environmental scores and carbon emissions to understand sustainability performance.

### 4. Company ESG Performance and Benchmarking
Compares individual company ESG performance with industry averages and identifies high- and low-performing companies.

## Key Features
- Interactive dashboards and slicers.
- KPI cards for important performance indicators.
- Industry and regional analysis.
- Company-level ESG benchmarking.
- DAX-based calculations and measures.
- Interactive visualizations.
